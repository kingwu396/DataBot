# DataBot 本地演示

当前阶段可以从 `predict` 选择日志或上传 `.log`、`.txt` 文件，通过异常识别 Agent 和问题分析 Agent 调用模型进行分析，查看处理范围和结果，并将历史保存在本机 SQLite。规则扫描提供辅助统计。上传文件上限为 300 MiB，分析完成后临时上传文件会被删除；原有 `predict` 日志只读。

## 启动

需要 Python 3.12 或更高版本（低于 3.15）、`uv`、Node.js 和 npm。在项目目录运行：

```bash
./start.sh
```

脚本使用 `backend/pyproject.toml` 和 `backend/uv.lock`，通过 `uv` 将后端依赖安装到独立的 `backend/.venv`，不安装到全局 Python 环境；必要时安装前端依赖，并启动 FastAPI 和 Vue。打开 <http://127.0.0.1:5173>，在运行脚本的终端按 `Ctrl+C` 停止。首次安装需要访问依赖源。

如果提示 8000 或 5173 端口被占用，确认占用它们的程序可以关闭后，在项目目录运行：

```bash
./stop.sh
```

该脚本会停止所有正在监听这两个端口的进程，包括可能属于其他项目的进程。随后可重新运行 `./start.sh`。

单独管理后端依赖时，在 `backend` 目录运行 `uv sync --locked`；单独启动后端时，在同一目录运行 `uv run uvicorn main:app --host 127.0.0.1 --port 8000`。

分析历史保存在 `data/databot.sqlite3`，可能包含日志片段，请按日志数据同等对待。

## 模型配置

网页中可分别配置本机 Ollama 和外部 OpenAI 兼容 API 的服务地址、模型名称；远程服务根据需要填写 API 密钥。两套配置分别保存，切换后选择要使用的一套并点击“保存配置”，两个 Agent 使用当前选中的配置分别执行识别和分析。新配置默认选择外部 API；已有配置会保留。

外部 API 地址填写服务商提供的基础地址（例如 `https://服务地址/v1`），然后填写其模型名称和 API 密钥。点击“测试连接”只会发送简短测试文本，不发送日志；之后选择日志并点击“开始分析”才会调用模型处理日志。远程服务可能产生调用费用。本机模式需要自行启动 Ollama 并准备好模型，例如 `qwen3.5:35b-a3b`，不使用本机模式时不需要启动 Ollama。

填写服务地址和所需密钥后，可点击“获取模型”并从下拉列表选择；该操作只获取服务端模型列表，不发送日志。服务不提供列表接口时仍可手动输入。更换远程服务地址后，需要重新输入该服务的密钥，避免将已保存的密钥发送到新地址。

用户可选择是否在发送给模型前脱敏。远程模型会接收日志分段和识别结果；关闭脱敏会发送原始内容，开启脱敏也不能保证覆盖所有敏感信息。API 密钥按用户选择以明文文件 `data/model_api_key` 保存在本机，文件权限为 `600`，不会上传到 Git；模型配置保存在本机 SQLite。

日志按顺序分段交给识别 Agent，页面显示已处理字节数；为分析阶段预留时间，如果无法处理完整文件，结果标记为“部分识别”。目前识别结果最多保留 80 条用于分析，超出数量会提示；模型给出的证据会标注是否在对应输入片段中精确匹配。
